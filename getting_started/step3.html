Forming the USB link

We use a PS4 controller to drive the robot. The communication between the PS4 controller and the computer is enabled by the program USB Network Gate. This program will use the shared local network to send your USB port of which the PS4 controller is plugged into to the LattePanda. The result is that the controller is wirlessly connected to the LattePanda.

The LattePanda already has USB Network Gate installed. For your PC you will need to install the same program before continuing.

  1. Plug the PS4 controller into your PC via USB.

  2. Open USB Network Gate on your PC and navigate to the Local USB devices tab. (Figure 1)

By the end of this section the robot is both powered on and connected to an external device ready to be given operating commands.
