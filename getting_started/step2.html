Establishing the Computer Connection

While within the robot, the LattePanda computer uses a network connection to communicate with external devices. We need to establish this connection to allow us to interface with the computer while physicaly isolated to the electronic box. This page explains the process of connecting to the computer with remote desktop.

The first step is to get both the LattePanda and your client PC on the same local network. For this we use a network router, a tp-link AX1800 4-Stream Dual-Band Wi-Fi 6 Router.

  1. Plug the router into an outlet and wait until the network TEAM_42 becomes an available network.

  2. Connect both the LattePanda and your PC connect to the TEAM_42 network. Note that if the LattePanda is plugged in and turned on, it should automatically connect to the TEAM_42 network.

  3. On your PC use the remote desktop connection application to establish a remote connection.

By the end of this section the robot is both powered on and connected to an external device ready to be given operating commands.
