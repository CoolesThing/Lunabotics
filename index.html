Detailed Robot Startup Procedures

The following describes the startup process of the robot. This section is designed to be highly detailed, therefore it's intended audience are people who are new to the robot. Those that are more familiar with the robot should review the Quick Start section instead. Before starting, read the listed items below. Confirm you have all of the following before continuing.

Equipment list:

  • LattePanda Computer
  • LattePanda Power Supply
  • Personal Computer (Your laptop)
  • PS4 Controller (wired)
  • Keyboard (wired)
  • Mouse (wired)
  • Router (AX1800 4-Stream Dual-Band Wi-Fi 6 Router)

Software Requirements:

  • USB Network Gate 11.0.x
